Before you start
⚠️ Disclaimer: This is a simulation for educational and illustrative purposes only. Results may differ from real-world outcomes and should not be used for real-world operational decisions.

Set the simulation, then watch it .

This tool runs a 500-trial Monte Carlo of the seeker geometry defined in app.py. Place a decision point above the field, scatter a few decoys around it, and run the model to see where the estimated line of sight actually lands.

01Select a map environment and configure your decision point and decoys.
02Run the simulation — it calls your Flask backend directly.
03Open View Map to see the impact scatter and summary stats.

What this runs

  • 500 Monte Carlo trials per run, fixed seed (42)
  • One radar transmitter, fixed at (0, 0) with peak power of 50,000 W
  • Each decoy adds a competing line-of-sight source
  • Results are ground-projected impact points
  • Nothing is stored — every run is stateless
